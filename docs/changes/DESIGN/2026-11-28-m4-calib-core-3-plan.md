Section 13, calibrate: the calibration video's plan (internal/calib). Fixed slots for each display rate (12, 30, 60), cell (4, 8, 12, 16) and mode, r x 4 code frames each, reserved whatever the size, so F is 4,896 for every size and the frame index names the slot; a slot is shown where its cell divides the size, the grid is at least 120 x 90 and condition 4 holds (480p 36 s, 720p 72 s, 1080p 104 s, 1440p 100 s, 4K 120 s). Frames follow S2's convention (session 0x5332, inner code 2, scramble bits alone, no descriptor) within FORMAT.md's ranges. How a calibration video is told from a transfer, with no reserved value: a codeword counts as decoded only when it decodes to the calibration's all-zero codeword, so a transfer matching the header pattern whose descriptor does not decode reads as a calibration in which no segment passes and gets no recommendation, and headers recovering to more than one video size are not a calibration video (review of M4's fifth pull request). The exit test's distance (sum of rank differences over rate, cell, mode and protection; within one step is at most 1); the recommendation, its pass thresholds (92% of codewords on the summed frames, 90% of code frames seen) and margin (96% and 95%), both provisional, pending G1, and the label measured on your device.
